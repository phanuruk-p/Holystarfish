# Holystarfish Jewelry Website

## อีเมลยืนยันคำสั่งซื้อ

เมื่อยืนยันสั่งซื้อสำเร็จ ระบบส่งถึงอีเมลสมาชิกผ่าน Gmail ที่ตั้งไว้ โดยแสดงเลข HS-xxxxxx วันที่และเวลาไทย รูป/ชื่อสินค้า จำนวน ราคาต่อชิ้น ยอดแต่ละรายการ ส่วนลด VAT 7% ค่าจัดส่ง และยอดชำระทั้งหมด พร้อมวิธีชำระเงิน สถานะ และที่อยู่จัดส่ง อีเมลออกแบบกว้าง 600px พร้อมภาพแนบ CID

ใช้ยอดที่บันทึกตอนซื้อโดยไม่คำนวณราคาใหม่ภายหลัง ปัจจุบันส่วนลดเป็น 0 และจัดส่งฟรี VAT ใช้การปัดเป็นบาทตามระบบเดิม อีเมลนี้เป็นการยืนยันรับคำสั่งซื้อ ไม่ใช่ยืนยันว่าชำระเงินแล้ว

ตาราง order_email_outbox เก็บข้อมูลอีเมล ณ เวลาสั่งซื้อในธุรกรรมเดียวกับคำสั่งซื้อ การกดยืนยันซ้ำไม่สร้างอีเมลซ้ำ หากส่งล้มเหลวคำสั่งซื้อยังคงอยู่ กรณี unknown/sending ค้างต้องตรวจสอบก่อนส่งใหม่ ไม่มีการส่งคำสั่งซื้อเก่าย้อนหลังอัตโนมัติ

ทดสอบด้วย `C:\xampp\php\php.exe tests/order-email.test.php` (จำลองการส่ง ไม่ส่งถึงลูกค้าจริง)

## ## ส่งอีเมลผ่าน Gmail ส่วนตัว

กำหนด email, password (รหัสแอป Google), site_url ใน data/smtp.local.php ไม่มีหน้าตั้งค่า SMTP ระบบใช้ PHPMailer 7.1.1 ผ่าน smtp.gmail.com พอร์ต 587 STARTTLS และแนบภาพสินค้าในอีเมล

ส่งอีเมลต้อนรับเมื่อสมาชิกตอบแบบสอบถามครบ และส่งอีเมลขอบคุณเมื่อสมัครรับข่าวสาร การสมัครซ้ำหรือแก้คำตอบไม่ส่งอีเมลที่ส่งแล้วซ้ำ ไม่ไล่ส่งรายการเก่าทั้งหมดอัตโนมัติ

email_outbox บันทึกสถานะ draft, sending, sent, failed, unknown โดย sent หมายถึง SMTP รับข้อความแล้ว ไม่รับประกันว่าเข้ากล่องหลัก unknown หมายถึงยังยืนยันผลไม่ได้ ต้องตรวจการส่งก่อนลองใหม่เพื่อหลีกเลี่ยงส่งซ้ำ

site_url ต้องเป็น URL จริงเพื่อให้ลูกค้ากดลิงก์ได้ ค่า localhost ใช้ในเครื่องเท่านั้น ห้ามแจกจ่าย data/smtp.local.php เพราะมีรหัสแอป โฟลเดอร์นี้อยู่ใน OneDrive ซึ่งอาจซิงก์ตามการตั้งค่าของเครื่อง

ทดสอบแบบไม่ส่งจริง: tests/smtp.test.php และ tests/email-delivery.test.php
ระบบแนะนำสินค้าและอีเมลต้อนรับ

สมัครที่ `register.php` แล้วระบบพาไป `questionnaire.php` เพื่อตอบ 6 ข้อ: ประเภท สไตล์ สี โอกาส งบ และผู้รับ จากนั้นแสดง 3 สินค้าที่ใกล้เคียงที่สุดในงบที่ `recommendations.php` สมาชิกเดิมเข้าได้จากบัญชีของฉัน ระบบใช้คะแนนจับคู่ ไม่ใช่ AI และอ้างอิงแค็ตตาล็อกตัวอย่างเดิม

`newsletter.php` รับอีเมลพร้อมความยินยอมและแสดงหน้าขอบคุณ การสมัครซ้ำไม่เพิ่มข้อมูลซ้ำ `email-preview.php` แสดงอีเมลต้อนรับเฉพาะผู้เข้าสู่ระบบ และ `email-preview.php?type=newsletter` แสดงอีเมลขอบคุณ ดาวน์โหลด HTML ได้ อีเมลกว้าง 600px ใช้ภาพสัดส่วน 4:3 ข้อความและลิงก์เป็น HTML ที่กดได้ ไม่ใช่ภาพทั้งฉบับ

`customer-data.php` เป็น PHP ดึงข้อมูลชื่อ อีเมล คำตอบ และสินค้าที่แนะนำของสมาชิกที่เข้าสู่ระบบเท่านั้น ไม่เปิดรายชื่อลูกค้าทั้งหมดหรือรหัสผ่าน ฟังก์ชันฝั่งเซิร์ฟเวอร์อยู่ใน `includes/recommendations.php` ฐานข้อมูลเดิมเพิ่มตาราง `customer_preferences`, `newsletter_subscribers`, `email_outbox` อัตโนมัติ ส่งผ่าน SMTP และบันทึกสถานะใน email_outbox

ก่อนส่งจริง ให้ตั้งตัวแปรสภาพแวดล้อม `HOLYSTARFISH_SITE_URL` เป็น URL HTTPS ของร้าน (รองรับ subfolder) ค่าเริ่มต้น `http://localhost:8000` ใช้ดูในเครื่องเท่านั้น ระบบยกเลิกรับข่าวสาร/ยืนยันอีเมลต้องเพิ่มก่อนส่งแคมเปญจำนวนมาก ภาพต้องเข้าถึงได้จากโดเมนจริง ทดสอบอีเมลใน Gmail/Outlook ก่อนเปิดใช้งาน

เปิดด้วย `C:\xampp\php\php.exe -S localhost:8000 router.php` และใช้ `http://localhost:8000/register.php` ห้ามเปิดไฟล์ PHP โดยดับเบิลคลิก หากใช้ Apache ต้องเปิดใช้ `.htaccess` ซึ่งป้องกันโฟลเดอร์ data/includes ห้ามนำ SQLite หรือไฟล์ต้นฉบับฐานข้อมูลขึ้นพื้นที่สาธารณะ

ทดสอบด้วย `C:\xampp\php\php.exe tests/recommendations.test.php` ใช้ฐานข้อมูลในหน่วยความจำ ไม่แตะข้อมูลลูกค้าจริง

เว็บร้านเครื่องประดับภาษา PHP สำหรับแบรนด์ Holystarfish รองรับการโชว์สินค้าแบรนด์ตัวเองและสินค้าแบรนด์เนมคัดสรร

## วิธีเปิดใช้งาน

1. ติดตั้ง PHP บนเครื่อง
2. เปิดโฟลเดอร์นี้ใน Terminal
3. รันคำสั่ง:

```bash
php -S localhost:8000 router.php
```

4. เปิด `http://localhost:8000`

ระบบสมาชิกใช้ SQLite และจะสร้างฐานข้อมูลไว้ที่ `data/holystarfish.sqlite` อัตโนมัติเมื่อเปิดเว็บครั้งแรก

## การค้นหาสินค้า

หน้า `products.php` มีสินค้าตัวอย่าง 10 รายการ ภาพจำลองเฉพาะแต่ละชิ้นและราคาตัวอย่าง 390–1,890 บาท ข้อมูลร่วมของทั้งสองหน้าอยู่ใน data/products.json และภาพอยู่ใน assets/products/ ควรเปลี่ยนเป็นข้อมูลและภาพสินค้าจริงก่อนจำหน่าย

ค้นหาจากคำสำคัญภาษาไทย เช่น `ต่างหูไข่มุก ใส่ทำงาน งบไม่เกิน 1,500` หรือ `มินิมอล ไม่เกิน 1000` รองรับช่วงราคา เช่น `1000-2000` และตัวกรองประเภท โทนสี สไตล์ โอกาส หมวดสินค้า และการเรียงราคา ตัวกรองทั้งหมดใช้ร่วมกัน ต้องตรงทุกเงื่อนไข การค้นหานี้ใช้กฎคำสำคัญในเบราว์เซอร์ ไม่ได้เชื่อมต่อ AI และไม่รองรับการตีความทุกประโยค

ตรวจสอบการค้นหาด้วย `node tests/catalog-search.test.cjs`

## ไฟล์หลักของเว็บไซต์

- `index.php` หน้าเว็บหลัก
- `assets/style.css` สไตล์หน้าเว็บ
- `assets/script.js` ลูกเล่นตะกร้าและฟอร์ม
- `assets/logo-holystarfish.jpg` โลโก้ร้าน
- `register.php` หน้าสมัครสมาชิก
- `login.php` หน้าเข้าสู่ระบบ
- `account.php` หน้าข้อมูลสมาชิก
- `includes/database.php` เชื่อมต่อและสร้างฐานข้อมูล SQLite

## การสั่งซื้อและชำระเงิน

เพิ่มสินค้าลงตะกร้า → เลือกช่องทางชำระเงิน → กรอกข้อมูลจัดส่ง → ยืนยันสั่งซื้อ ระบบบันทึกคำสั่งซื้อใน SQLite และแสดงประวัติที่ `orders.php` เฉพาะลูกค้าเจ้าของรายการ มีปุ่มประวัติคำสั่งซื้อในบัญชีของฉัน

รองรับการเลือกโอนธนาคาร พร้อมเพย์ และเก็บเงินปลายทาง โอนเงิน/พร้อมเพย์บันทึกสถานะรอชำระเงิน ยังไม่เชื่อมผู้ให้บริการรับชำระเงินหรือแสดงเลขบัญชี/QR ของร้าน ไม่มีการตัดเงินอัตโนมัติ ยอดรวมคำนวณจากราคาสินค้าฝั่งเซิร์ฟเวอร์ บวก VAT 7% ตามตะกร้าเดิม และจัดส่งฟรี

รีเซ็ตข้อมูลคืนข้อมูลผู้รับจากบัญชีและล้างวิธีชำระเงิน รีเซ็ตตะกร้าล้างสินค้าโดยไม่ลบประวัติ หลังสั่งซื้อสำเร็จจะหักรายการที่ซื้อออกจากตะกร้า การส่งคำสั่งซื้อเดิมซ้ำไม่สร้างรายการซ้ำ

ตรวจสอบ: `C:\xampp\php\php.exe tests/orders.test.php` ใช้ SQLite ในหน่วยความจำ ไม่แก้ฐานข้อมูลจริง ตัวแปร `HOLYSTARFISH_DB_PATH` ใช้ระบุฐานข้อมูลแยกสำหรับทดสอบได้
